# Security policy

## Supported versions

Security fixes are provided for the latest published Live Downloader release.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/daviblro/live-downloader/security/advisories/new). Do not open a public issue for a suspected vulnerability.

Include the affected version, reproduction steps, impact, and any suggested mitigation. Maintainers will acknowledge the report as soon as practical and coordinate disclosure after a fix is available.

Only record streams you are authorized to download. Reports about bypassing a streaming service's access controls are out of scope.
